# E-Clean Pro Services LLC

Single-page marketing site with an interactive commercial cleaning price calculator and booking form.

## Stack

Static HTML/CSS/JS — no build step, no dependencies.

## Local preview

Open `index.html` directly in a browser, or serve it:

```bash
npx serve .
```

## Deploy (Vercel)

This is a zero-config static site. Push to GitHub, then import the repo in Vercel — no framework preset or build command needed (Vercel serves `index.html` as-is).
